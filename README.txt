Word Practice Notebook (JDK 21)

Compile (from this folder):
  mkdir out
  javac -d out src/*.java
Run (from this folder, so the data/ folder is found here):
  java -cp out Main

In an IDE (IntelliJ/Eclipse): create a project, copy the 6 files from src/ into it,
set the working directory to the project root, and run Main.
